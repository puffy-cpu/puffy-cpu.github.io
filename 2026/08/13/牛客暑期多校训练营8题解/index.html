B题 Deep Finesse

📖 题意

数字宇宙中包含 1 到 10¹⁰⁰ 的所有整数。汐从中选出 n 个互不相同的数字作为手牌，其余归风子所有。接下来 n 轮，每轮风子先出一个数字，汐必须用一个尚未打出的数字回应；若风子的数字严格小于汐回应的数字，风子立即获胜；只有汐的数字小于等于风子的数字时才安全过关。汐要撑完全部 n 轮才算获胜。此外风子会预先指定 m 个数字，要求汐的手牌必须包含这些数字。求所有大小为 n 且包含这 m 个指定数字的手牌中，有多少副能让汐拥有必胜策略，答案对 998244353 取模。

1≤m≤n≤5000，n 总和不超过 5000。

💡 思路

把手牌看作 1 到 2n 范围内的选择（可以证明只需在合并排序后的相对大小关系里考虑，最终问题等价于从 1 到 2n 中选 n 个数作为汐的手牌，即把 1 到 2n 分成两个各含 n 个数的集合）。设 aᵢ=1 表示第 i 小的数属于汐的手牌，aᵢ=-1 表示属于风子。汐必胜的充要条件是对所有 1≤i≤2n，前缀和 ∑ⱼ₌₁ⁱ aⱼ ≥ 0，直觉上就是风子每打出一张”-1”，汐都要能从左侧（更小的数中）找到一张”1”来应对（保证能用不超过对方的数回应）。

由此转化为格路计数（类似卡特兰数的约束）：设 dp[i][j] 表示考虑前 i 个位置、当前前缀和为 j 的方案数，若第 i 个位置被指定必须是汐的手牌（对应 a=1），则 dp[i][j]=dp[i-1][j-1]；否则 dp[i][j]=dp[i-1][j-1]+dp[i-1][j+1]（可以自由选择这个位置属于谁，但前缀和不能为负）。边界 dp[0][0]=1，答案为 dp[2n][0]。

时间复杂度 O(n²)。

G题 Multiplication

📖 题意

给定三个正整数 a、b、c，构造两对正整数 (x1,y1) 和 (x2,y2)，满足：x1 和 x2 均至少 a 位且前 a 位相同；y1 和 y2 均至少 b 位且前 b 位相同；但 x1·y1 与 x2·y2 均至少 c 位，且前 c 位不同。

1≤a,b≤10⁵，1≤c<a+b-1。

💡 思路

利用进位构造：让一个乘积恰好是 999999… 形式（一堆 9），另一个恰好是 1000000… 形式（进位后变成一堆 0 开头），这样它们的前若干位必然不同（一个全 9，一个是 1 开头全 0）。

注意到 1/3=0.333…，可以构造 x1=x2 都取 3 开头的一串数字（如 3333…3 或 3333…4），y1、y2 取一个大致是 3 后面跟一串 0 的形式，使得两者相乘时一个恰好在进位边界之下（产生一串 9），另一个恰好越过边界产生进位（一串 0 开头）。只要构造出的数字位数不超过题目给的范围（不超过 5×10⁵ 位）即可满足要求。

H题 It’s a Magic, Not a Trick!

📖 题意

给定 n 张符咒，第 i 张初始有 aᵢ 单位能量（正整数）。每次施法必须依次执行：灌注（任选一张符咒能量加 1）、释放（任选一张灌注后能量至少为 x 的符咒，消耗其 x 点能量）；若灌注后没有任何符咒达到 x 点能量，则本次施法失败，且灌注也不生效。可以施放任意多次，前提每次都成功，且所有能量始终非负。求所有符咒剩余能量之和的最小值，对 998244353 取模。

1≤n≤2×10⁵，1≤x≤10⁹，1≤aᵢ≤10¹⁸。

💡 思路

若 x=1，无法执行任何释放操作（因为灌注后至少是 1，但释放会让它变回 0，这样的”操作”本质上没有意义，题目里 x=1 时视为无法进行），答案就是原始总和。以下讨论 x≥2 的情形。

每次成功的操作会使总能量减少 x-1（灌注+1，释放-x，净变化 -(x-1)），所以要最小化总和，等价于最大化操作次数 k，答案为总和 - k(x-1)。

对每个 aᵢ 做带余除法 aᵢ=qᵢx+rᵢ，无论后续 +1 如何分配，qᵢ 次纯粹靠自身余数积累的减法操作总是可行的，记 p=∑qᵢ 为这部分”免费”能做的操作次数上限。执行完这些操作后，数组变为各个 rᵢ，同时还有 p 次可自由分配的 +1 机会。

对每个 rᵢ>0，需要 cᵢ=x-1-rᵢ 次 +1 才能让它达到 x（从而多做一次操作）。为了让操作次数最大化，把 cᵢ 从小到大排序，依次用 p 中的”预算”去购买，能买则操作数+1、p 减少 cᵢ。购买完之后如果 p 还有剩余，还可以继续做 ⌊p/(x-1)⌋ 次”全新”的完整操作（相当于纯粹靠灌注攒出 x-1 差值反复操作）。

时间复杂度 O(n log n)。

I题 Bridge VI

📖 题意

有 2n 名参赛者，参赛者 2i-1 与 2i 进行比赛（i=1..n），每场比赛的 m 分可以任意实数方式分配给两名选手。参赛者初始分数为 aᵢ，最终分数为初始分数加上比赛所得分数。大豆是参赛者 1，求在所有合法分配方式下，最终分数严格大于他的参赛者人数的最小值和最大值。

1≤n≤2×10⁵，1≤m≤10⁹，1≤aᵢ≤10⁹。

💡 思路

设大豆最终得分为 x。大豆表现最好时 x=a1+m（自己那组的 m 分全拿），最差时 x=a1（自己那组的 m 分全给对方）。

对于不与大豆同组的每一组选手（初始分 u、v）：

求最多多少人超过大豆时，用大豆表现最好的 x=a1+m 作为基准：若 u+m>x 且 v+m>x 且 u+v+m>2x，说明存在一种分配方式让两人都超过 x，贡献 2；若 u+m>x 或 v+m>x（至少一个能超过），贡献 1；否则贡献 0。

求最少多少人超过大豆时，用大豆表现最差的 x=a1 作为基准：若 u>x 且 v>x，则无论怎么分配这组的 m 分，两人必然都超过 x（因为初始分已经超过），贡献 2；若 u≤x 且 v≤x 且 u+v+m≤2x，则存在分配方式让两人都不超过 x，贡献 0；否则贡献 1（必然至少一人超过）。

对于与大豆同组的选手（初始分 a2）：大豆自己拿到 x 后，队友拿到 m-(x-a1)，直接与对应基准比较即可得到该选手的贡献。

对每组分别计算并累加，时间复杂度 O(n)。

M题 KV Cache

📖 题意

维护一棵容量为 m（边数上限）的字典树（Trie）作为 KV 缓存。依次处理 n 个字符串请求：处理请求时沿 Trie 从根走，已存在的边零代价复用，缺失的边需要花费 1 单位计算量并加入树中（一个请求内所有缺失边先全部加入，即使暂时超过 m 条边）。处理完一个请求后，若边数超过 m，需要反复删除叶节点（及其到父节点的边）直到恰好剩下 m 条边，可以自由选择删哪些叶节点。求处理完所有请求的最小总计算代价。

1≤n≤10⁶，1≤m≤10⁹，所有字符串长度之和不超过 10⁶。

💡 思路

这是经典的缓存替换问题，类似操作系统中的 Bélády 最优置换算法（OPT）：每次需要淘汰时，优先淘汰”下次被使用时间最晚”的页面，这样能保证未来的缺页（这里是重新计算）次数最少。

本题的特殊之处在于有 Trie 的树形结构约束（只能删叶节点），但可以证明：对于一对祖先-后代关系的结点 u→v，u 的下次使用时间一定不晚于 v 的下次使用时间（因为访问 v 必然先经过 u，所以 u 的下次使用时刻发生在 v 的下次使用时刻之前或同时）。这意味着更深的结点天然会更早成为”下次使用时间最晚”的候选，天然满足只能删叶节点的约束——按 Bélády 策略贪心删除的永远自动是叶节点。

因此只需要用优先队列维护当前 Trie 中所有已缓存结点的”下次使用时间”，每次需要淘汰时取出下次使用时间最晚的结点删除即可（配合每个结点维护子结点计数，只有子结点数为 0 才是真正的叶节点可删）。

预处理时对每个字符串建 Trie，同时对 Trie 上每个结点记录它在哪些请求中被访问到（对应的请求编号序列），从而能计算某结点当前的”下一次被访问的请求编号”。

时间复杂度 O(N log N)，其中 N≤10⁶ 为 Trie 的结点数目。
