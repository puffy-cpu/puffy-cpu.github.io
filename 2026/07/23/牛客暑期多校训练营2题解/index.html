B题

📖 题意

给定一个长度为 n 的非负整数数组，将所有数字分别放入两个多重集合中，设两个集合的异或和分别为 xor1 和 xor2，求 xor1 + xor2 的最大值。

💡 思路

设所有数字的异或和为 S = a1 ⊕ a2 ⊕ ... ⊕ an，那么两个集合的异或和 x,y 一定满足 x ⊕ y = S。

根据 x + y = (x ⊕ y) + 2(x & y)，有 x + y = S + 2(x & y)。

因此只需要最大化 x & y。

对于 S 中为 1 的位，x 和 y 在这一位必须不同，因此只有 S 中为 0 的位才能同时出现在 x 和 y 中。

对于每个 a[i]，去掉其中所有和 S 相同的二进制位，剩余部分建立线性基。在线性基中求最大异或值 x，答案即为 S + 2x。

M题

📖 题意

给定一个初始没有边的 n 个点无向图，现在添加恰好 m 条无向边，求满足“两个点之间存在路径但没有直接边”的点对数量最大值。

💡 思路

如果一个连通块有 s 个点，那么其中共有 s(s-1)/2 个点对。

当 m < n-1 时，无法让所有点连通。最优方案是用 m 条边构造一棵树，此时树有 m+1 个点，共有 (m+1)m/2 个连通点对，其中 m 对存在直接边，因此答案为 m(m-1)/2。

当 m >= n-1 时，先用 n-1 条边构造一棵生成树，使所有点连通。此时满足条件的点对有 n(n-1)/2-(n-1) 个。剩余 m-(n-1) 条边每增加一条都会使一个点对变成直接相连，因此答案为 n(n-1)/2-(n-1)-(m-n+1)，即 (n-1)(n-2)/2-m+n-1。

N题

📖 题意

给定一个长度为 n 的数组，一次操作选择任意 k 个元素，求它们的中位数并将这 k 个元素全部修改为中位数。要求恰好操作一次，求操作后整个数组元素和的最大值。

💡 思路

先将数组排序为 a1 <= a2 <= ... <= an。

如果 k 为奇数，设 k = 2x+1，枚举中位数 a[i]。为了使结果最大，左边选择最小的 x 个元素，右边选择 a[i] 后面的 x 个元素。操作后这 k 个元素全部变成 a[i]，因此可以利用前缀和计算答案。

如果 k 为偶数，设 k = 2x+2，枚举中间两个元素 a[i],a[i+1]。中位数为 (a[i]+a[i+1])/2，因此操作后这 k 个元素的总和为 (k/2)(a[i]+a[i+1])，同样利用前缀和计算即可。

G题

📖 题意

存在一个无限有向图，点为正整数。对于任意 i < j，存在一条 i -> j 的边，边权为 gcd(i,j)。

定义 cost(u,v) 为从 u 到 v 的最小路径代价。给定 l,r,n，求 cost(l,n) + cost(l+1,n) + ... + cost(r,n)。

💡 思路

由于所有边都满足 i < j，所以路径一定严格递增。

如果 gcd(i,n)=1，可以直接从 i 走到 n，费用为 1；如果 gcd(i,n)>1，通常可以通过中间节点跳转，使费用为 2。

设 p 为不超过 n 的最大质数，将区间分成 i < p 和 i >= p 两部分。

对于 i < p，只需要统计区间中与 n 互质和不互质的数量。将 n 分解质因数后，用容斥原理统计不互质的数量，答案为 good + 2 * bad。

对于 i >= p，因为这一段长度很小，可以直接做 DP。定义 dp[i] = cost(i,n)，转移为 dp[i] = min(dp[j] + gcd(i,j))，枚举所有 j > i 即可。
